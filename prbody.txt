## For humans
- On the web page, an embedded web page now shows up in a locked-down frame at its set height, instead of a single fallback line. Static sites (no JS) write the same frame.
- Under the frame, a small caption shows the page's address and an "open ↗" link that opens it in a new tab, which is the way out when a site refuses to be framed.
- An address that isn't http or https shows a muted "This page can't be shown here." box at the same height.

## What changed
- `web/src/render/web.ts`: the view from the approved design (docs/design/web). It's a `div.web` root, whose hooks come from `render` (`b b-web`, `data-block`, `data-id`; `web` has no parts or variant in `gen/hooks.ts`). Inside are `iframe.wf` and `div.wm` (the `span.wu` address and the `href()` link). `src` is read with `new URL(src, document.baseURI)`; only http/https give a frame, anything else gives `div.wf.none`. The frame has `sandbox="allow-scripts allow-forms allow-popups allow-popups-to-escape-sandbox"`, `allow=""`, `referrerpolicy="no-referrer"`, `loading="lazy"` and the address as its `title`. No script is added to the host page.
- `crates/blocks/src/site/views.rs` `web` (B8 landed during this round): writes the same element. A `src` with a scheme other than http/https gives the muted box. `fixtures/html/web.html` is regenerated, and site.test's per-kind comparison passes.
- Fix round 2 (security): the static writer now reads `src` the way a browser's URL parser does before checking its scheme. It trims leading and trailing control characters and spaces, and drops tab, CR and LF anywhere. So `java\tscript:…`, `java\nscript:…` and ` \^AJavaScript:…` write the muted box with no frame or link, the same as the live view. There's a new Rust test (`tests/site.rs`) that drives `site::fragment`: it fails on the old writer (an `<iframe>` for `java\tscript:`) and passes now. render.test's non-http list has the same strings.
- Merged origin/staging (#39 secret): `gaps` drops both secret and web, and both test sets are kept. `web/dist` was rebuilt.
- `index.ts`: `web: gap(41)` → `web`. `blocks.css`: the design's five token-only rules.
- `patch.ts`: one line. A redraw whose new node equals the old one and holds an iframe keeps the old node, so the same `src` doesn't reload (the design's "A redraw with the same src keeps the frame").
- Generated (gen steps, not hand-edited): `fixtures/trees/web.json` (drawn `native`), `fixtures/html/web.html`, `web/dist`.
- Tests: the fixture's frame attributes, height, caption and link; the caption of an absolute address; non-http `src` (javascript:, data:, unparseable) gives the box with no frame or link; through the real patcher, a same-`src` merge keeps the iframe node and a new `src` replaces it. The test DOM shim gets `isEqualNode`, and patch.test's El gets `querySelector`.

Decisions:
- The caption is the `src` with `http(s)://`, query/hash and the trailing `/` dropped (`https://cooee.app/doc` → `cooee.app/doc`, as designed). The static writer has no page address, and site.test needs the same text from both writers. So a relative `src` shows as written (the fixture's `/doc`) rather than with the page's host.
- The frame and link still resolve a relative `src` against the page (amendment q2182).
