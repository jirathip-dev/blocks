# `plot`

A line plot of named series over a numeric or time x: points stream in by `points`; a window, a target and a peak.

The Rust type `Plot`; in TS, `plot(fields: Plot)` from `web/src/gen/builders.ts`.

## Fields

| field | type | |
|---|---|---|
| `empty` | `string` | optional |
| `id` | `string` | optional |
| `peak` | `Peak` | optional |
| `series` | `Trace[]` | required |
| `show` | `Expr` | optional |
| `target` | `Target` | optional |
| `title` | `string` | required |
| `window` | `number` | optional |
| `x` | `Axis` | optional |
| `y` | `Axis` | optional |
