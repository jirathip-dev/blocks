6 · the frame
Every frame is the same sandboxed iframe. The page runs in an opaque origin: no cookies, no storage, no access to the host page, like Swift's non-persistent store. It may run its own scripts, send forms and open new windows (which leave the sandbox, so links work). It cannot navigate the host page, ask for the camera, microphone or location, or see the host's address. Nothing is added to the host page itself.
