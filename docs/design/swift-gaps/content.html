Blocks

Typed screens, sent as JSON and patched by ops. A prose block is a tree of parts, so no renderer needs a markdown reader; see the schema and Prose::new().

  • one schema, 27 kinds
  • a fallback for every app kind
  • patches, not repaints
  1. build the screen
  2. send it
  3. patch it as it changes
Built by type, drawn by every renderer.

At phone width the links scroll sideways under a fade, with no menu button. hero: title, subtitle, media, then its actions (the first one primary). media: its box takes width×height before the picture loads; alt shows until then; a video shows its poster and a play button and plays in place.
