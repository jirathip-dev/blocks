look

One code carries a whole look: the style on every axis, and the name of a scheme pair. It is short enough for a link, a chat line or an app's config.

The code

10lspy~BAMvLyAAEAFbAV0.console
versionone character; this reader takes 11
style5 characters, 0-9 a-z: the ten axes packed as one number0lspy
labels~ then the role labels, URL-safe; left out when none~BAMv…
scheme. then a name; left out for blocks' own pair.console

Style axes, in order

Each axis is a digit of the number, in this order; its first value is the default. A newer blocks adds an axis as a higher digit, so every old code still reads the same. Space, radius and motion go in quarter steps; a style off a step has no code, and encoding it says which axis.
1. typethe lowest digitdefault 0 · mono 1 · serif 2
2. space0, 0.25, 0.5 … 4 (17 steps)
3. radius0, 0.25, 0.5 … 4 (17 steps)
4. motion0, 0.25, 0.5 … 4 (17 steps)
5. easingstandard 0 · calm 1 · bouncy 2
6. surfaceglass 0 · dashed 1 · solid 2
7. fillstint 0 · outline 1 · solid 2
8. buttonsplain 0 · filled 1
9. markssymbols 0 · text 1
10. sectionstitle 0 · quiet 1

Labels

For each decorated role, in this order: kind, header, group, section, title, button, chip, back, said, picked. Each gives its case (as-is, lower, upper), its prefix and its suffix, as bytes, then all of it as URL-safe base64.

Scheme

The part after the dot only names a pair: a swag pack, or the app's own look. blocks keeps no list of names and carries no colours. An app that has no pair by that name wears the style on blocks' own pair and says so.

In an app

use blocks::theme::LookCode;

let look: LookCode = "108bd0.paper".parse()?;   // Err(CodeError::Version('9')) on "9…"
look.style      // a Style, every axis set
look.scheme     // Some("paper"): the app resolves it, None is theme::default()
look.to_string() == "108bd0.paper"            // encode: the same code back
import { mount, lookCode } from "blocks";

mount({ root, layout, schemes, look: "108bd0.paper" });  // the app's own look
lookCode.decode("108bd0.paper")   // { style, scheme: "paper" }; throws on a bad code
lookCode.encode(style, "paper")  // "108bd0.paper"

When a code is wrong

Opening the site with a code it cannot read keeps the look you had. Each case shows one toast:
✕This look code is version 9; this site reads version 1. Your look is unchanged.
✕This look code was made by a newer blocks. Your look is unchanged.
!No scheme “dusk” here: wearing the shared style on the default colours.
✕“hello” is not a look code. Your look is unchanged.
