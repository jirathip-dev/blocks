Shop · products

1 · Empty

A drop area with [choose file] and the hint drawn from what the screen declares (.xlsx or .csv, its row limit). Under it, the columns the file needs, in bold, and the optional ones with their allowed values. [download template] makes an empty workbook with these headers, on the device.

2 · File picked: columns matched, rows previewed

Each declared column is matched to a header in the file by its label, its key or an also name, so most files need no change. Each column has a select to change the match; under it, two sample values. A header nothing asked for (Supplier) is listed as not imported. The rows show as the screen will store them, numbered by their row in the spreadsheet, so a user can find one in Excel.

3 · Row errors

Every row is checked on the device: a required cell that is empty, a number or date that does not read, a value outside the allowed list, a repeated unique key. A bad row gets a red edge, its bad cell is marked "!", and the reason is on the line under it. [4 with errors] shows only those rows. Rows with errors are left out of the import: the user fixes the file and picks it again, or imports the rest. Cells are not edited here.
