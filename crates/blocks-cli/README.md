# blocks-cli

`blocks check`: the guard's lint and ratchet over an app's screen fixtures, and `blocks new` for an app's own kind.
Part of [blocks](https://github.com/jirathip-dev/blocks).

```sh
cargo install blocks-cli
```

How an app pins and upgrades blocks: [docs/consume.md](https://github.com/jirathip-dev/blocks/blob/main/docs/consume.md).
