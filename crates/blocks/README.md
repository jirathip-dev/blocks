# blocks

Typed UI blocks, their row diff and ops, the device stream protocol, the theme rules and the HTML renderer's files:
the Rust side of [blocks](https://github.com/jirathip-dev/blocks).

```sh
cargo add blocks
```

How an app pins and upgrades blocks: [docs/consume.md](https://github.com/jirathip-dev/blocks/blob/main/docs/consume.md).
